# TG Labs V6.1 Production Launch

## What changed

- Standardized the Next.js App Router entry points under `app/`.
- Removed unused root-level `page.tsx`, `layout.tsx`, and `globals.css` duplicates.
- Added production metadata, canonical URL, Open Graph metadata, viewport, and robots directives.
- Added `sitemap.xml` generation for the public routes.
- Added `/api/health` for deployment smoke checks.
- Refined the homepage copy from V6 to V6.1 production-launch wording.
- Added keyboard focus states and small-screen layout improvements.

## Vercel settings

- Framework preset: Next.js
- Root Directory: `./`
- Build Command: `npm run build`
- Install Command: default
- Production branch: `main` after the V6.1 branch has passed verification

## Required pre-domain checks

1. Deploy the `v6.1-production-launch` branch to a Vercel preview.
2. Confirm the build completes successfully.
3. Open `/` and verify the homepage renders.
4. Open `/auth`, `/patient`, `/technician`, and `/admin` and verify each route loads.
5. Open `/api/health` and confirm JSON contains `status: "ok"` and `version: "6.1"`.
6. Confirm `/sitemap.xml` and `/robots.txt` return successfully.
7. Configure production environment variables only in Vercel; never commit secrets to GitHub.
8. Connect `www.tglabs.in` only after the preview passes the smoke checks.
9. Keep the current working Vercel deployment available as rollback until the custom-domain smoke test passes.

## Important scope note

V6.1 is the production-launch web shell and deployment hardening pass. Live OTP, database, Razorpay, WhatsApp, LIS/report delivery and other external integrations still require their real production credentials and services before those workflows can be treated as live transactional functionality.
