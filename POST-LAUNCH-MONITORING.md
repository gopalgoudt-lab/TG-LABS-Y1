# TG Labs V6 — First 30 Days Monitoring

Monitor daily:
- Unique visitors
- Test searches
- Booking starts
- Completed bookings
- Checkout abandonment
- Payment success/failure
- Home collection demand
- Slot utilization
- Technician completion rate
- Report publication latency
- Notification delivery
- 4xx/5xx errors
- API latency
- Database errors

Review weekly:
- Conversion funnel
- Search terms with no results
- Failed payments
- Customer support issues
- Accessibility issues
- SEO indexing
- Core Web Vitals

Do not send patient medical information or secrets to analytics systems.
