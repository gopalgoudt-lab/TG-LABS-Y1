# TG Labs V6 — Production Operations

Daily:
- Check payment reconciliation.
- Check failed bookings.
- Check report queue.
- Check notification failures.
- Check technician collection exceptions.
- Review security alerts.

Weekly:
- Review backups.
- Review failed webhook events.
- Review access/audit logs.
- Review uptime and API latency.
- Review conversion funnel.

Monthly:
- Test backup restore.
- Review admin accounts.
- Rotate credentials according to approved policy.
- Review dependencies and security advisories.
- Review privacy/data-retention controls.

Business owners should keep actual prices, test availability, locations, service areas and policies verified and current.
