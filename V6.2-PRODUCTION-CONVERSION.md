# TG Labs V6.2 — Production Conversion

V6.2 is an incremental conversion release based on the deployed V6.1 homepage. The existing visual language is retained rather than rebuilding the site.

## Included in this branch

- Conversion-focused homepage hero and search experience.
- Interactive test search for the starter catalogue.
- Popular test shortcuts.
- Local basket persistence with add/remove actions.
- Booking entry point at `/checkout`.
- Home collection vs centre booking selection.
- Patient name, mobile, address, date and preferred slot capture.
- Responsive commercial homepage and checkout styling.
- Existing patient, technician, admin, auth, robots and sitemap routes remain in place.

## Important production boundary

The checkout screen intentionally does **not** charge a patient. Razorpay/payment processing, real availability, OTP authentication, notifications, database persistence and report delivery must be connected and tested before the custom domain is switched to this release.

## Go-live sequence

1. Preview deploy this branch in Vercel.
2. Test homepage → search → add to cart → checkout on desktop and mobile.
3. Connect the production backend/database and real catalogue.
4. Configure OTP/authentication and role protection.
5. Configure payment gateway and server-side payment verification.
6. Configure WhatsApp/SMS/email booking notifications.
7. Run production smoke tests.
8. Only then connect `www.tglabs.in` to the verified production deployment.
