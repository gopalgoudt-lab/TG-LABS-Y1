# TG Labs V6.3 — Backend Foundation

V6.3 keeps the V6.2 homepage and checkout experience intact while introducing the first production backend boundary.

## Included

- PostgreSQL Prisma schema for patients, diagnostic tests, bookings and booking items.
- Initial database migration under `prisma/migrations`.
- Seed catalogue for the six V6.2 starter tests.
- `GET /api/tests` for active diagnostic tests.
- `POST /api/bookings` with Zod validation and server-side price calculation.
- Checkout connected to the booking API.
- `/api/health` now verifies database connectivity.
- Prisma generation is executed during deployment through `postinstall`.

## Required Vercel configuration

Set `DATABASE_URL` in the Preview and Production environments to the production PostgreSQL connection string.

After the first production deployment, run the schema deployment against the production database:

```bash
npm run db:deploy
npm run db:seed
```

Do not put database passwords, Razorpay secrets, OTP credentials or report-storage credentials in GitHub. Use Vercel Environment Variables.

## Not enabled yet

- Razorpay order creation/capture/webhook verification.
- OTP provider integration.
- WhatsApp/SMS/email notifications.
- Technician assignment and operational scheduling.
- Report upload/storage delivery.
- Patient session authorization.

## Release gate

V6.3 should remain a preview until the database is connected, migration succeeds, seed data is present, `/api/health` returns `status: ok`, and a test booking creates a real database record. Only then should the payment layer be added in V6.4.
