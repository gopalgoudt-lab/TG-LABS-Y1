# TG Labs V6 — Data Governance Checklist

For production, TG Labs should maintain approved policies for:

- Patient data collection
- Consent
- Data minimization
- Access control
- Report retention
- Deletion/archival
- Vendor access
- Audit logging
- Security incidents
- Backup retention
- Data export requests

Use only approved legal/privacy language. Do not make regulatory or certification claims unless verified and current.
